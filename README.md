# Flow Website

Site web officiel de **Flow** — micro-entreprise de conception et développement de solutions digitales sur mesure.

## Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion

## Développement

```bash
npm install
npm run dev
```

## Scripts

| Commande | Description |
| --- | --- |
| `npm run dev` | Serveur de développement |
| `npm run build` | Build de production |
| `npm start` | Lancer le build |
| `npm run lint` | Lint |
