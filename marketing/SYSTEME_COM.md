# Flow — système de communication

**Charte graphique :** `CHARTE_GRAPHIQUE.md` · design system vivant : `/hq/design-system`.

**Objectif :** clients + partenariats + réseau LinkedIn (recruteurs inclus).  
**Positionnement :** ingénieur qui livre des produits digitaux (sites, apps métier, plateformes) — fondateur de Flow. Pas “freelance sites vitrine”.

## Rôle de chaque canal

| Canal | Rôle | Fréquence |
|--------|------|-----------|
| **LinkedIn perso (Adams)** | Autorité + réseau + clients B2B + recruteurs + partenariats | 3 posts / semaine + 10–15 interactions / jour |
| **LinkedIn page Flow** | Offre, preuves, partenaires | 1–2 posts / semaine |
| **WhatsApp** | Activation du réseau déjà chaud | 1 message / 1–2 semaines max |
| **Site Flow** | Preuve + conversion (formulaire → Resend) | Toujours à jour |

## Perso vs page entreprise

| | Profil Adams | Page Flow |
|--|--------------|-----------|
| **Dit** | Je / métier / leçons / preuves vécues | Nous / offre / livraisons / partenaires |
| **But** | Confiance + réseau + opportunités | Marque + leads + crédibilité entreprise |
| **Éviter** | Catalogue froid | Copier-coller du post perso |

Les deux se renvoient (mention / lien), sans le même texte mot pour mot.

## LinkedIn — 4 piliers (rotation)

1. **Preuve** — une réalisation, un détail technique utile, un avant/après métier  
2. **Métier** — cadrage, paiement, multi-rôles, déploiement, dette technique…  
3. **Offre** — une des 3 portes (site / app / plateforme) sans catalogue agressif  
4. **Réseau** — question ouverte, leçon, partenariat, “qui connaît…”  

Ratio conseillé perso : **2 preuve/métier · 1 offre** sur 3 posts.  
Page Flow : plutôt **preuve / offre / partenaire**.

## Cadence LinkedIn (réaliste)

- **Lun / Mer / Ven** : 1 post perso  
- **1× / semaine** : 1 post page Flow (ex. mardi ou jeudi)  
- **Chaque jour ouvré** : 10 commentaires utiles  
- **Dimanche 30 min** : skill `flow-com` → brouillons dans `linkedin/`

## WhatsApp — règles

- 1 visuel + **3–5 lignes max** + 1 CTA clair  
- Destinataires : contacts qui peuvent acheter ou recommander  
- Jamais de blast quotidien ; privilégier statuts + envoi ciblé  
- Visuels prêts : `visuels/`
