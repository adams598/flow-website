# Créer la page entreprise LinkedIn — Flow

Temps estimé : 5–10 minutes.

## Étapes

1. Sur LinkedIn, ouvre le menu **Pour les entreprises** (ou cherche “Créer une page LinkedIn”).
2. Choisis **Entreprise** (petite structure / 1 personne OK).
3. Remplis :
   - **Nom** : Flow  
   - **URL personnalisée** : idéalement `linkedin.com/company/flow-…` (si “flow” est pris, `faireflow` ou `flow-by-adams`)  
   - **Site web** : URL du site dès qu’elle est en ligne (sinon laisse vide temporairement)  
   - **Secteur** : Développement de logiciels / Services informatiques  
   - **Taille** : 1 employé  
   - **Type** : Privée  
   - **Lieu** : Mantes-la-Ville, Île-de-France, France
4. **Logo** : export carré de la marque Flow.  
5. **Bannière** : utilise `public/linkedin-banner-b.png` (ou `-a` / défaut).
6. **Tagline / description courte** :

```
Build digital. Make it flow.
Sites web · Applications métier · Plateformes digitales
Du cadrage à la mise en production.
```

7. **À propos** (plus long) :

```
Flow conçoit et développe des sites web, applications métier et plateformes digitales sur mesure.

Trois portes d’entrée :
• Sites web — présence digitale qui sert le commercial
• Applications métier — digitaliser un process (back-office, workflows, espaces clients)
• Plateformes — produit digital (abonnements, multi-rôles, marketplace…)

Un interlocuteur technique, du besoin jusqu’au run.

Contact : adamsdexter3@gmail.com · 07 49 17 83 91
```

8. Ajoute-toi comme **super-administrateur**.
9. Sur ton **profil perso** → expérience Flow → rattache l’entreprise à cette **Page** (pas seulement le nom texte).
10. Bouton d’action de la page : **Visiter le site** ou **Nous contacter** → URL du site avec ancre `#projet` si possible.

## Cadence page Flow

- 1–2 posts / semaine (voir `page-flow-posts.md` et `calendar.md`).
- Ne copie pas les posts du profil Adams.
- Objectif : marque + leads + partenaires, pas le storytelling perso.
